# Audition Portfolio

A shareable one-page portfolio for acting, ads, and modelling opportunities.

Open `index.html` in a browser to view it.

Personalize the site:
- Edit `script.js` for name, intro, bio, stats, contact details, photo titles, and clip titles.
- Add photos to `media/photos/`.
- Add audition clips to `media/videos/`.

Expected media filenames are listed in `media/README.md`.

Deployment-ready files are included for GitHub Pages, Netlify, and Vercel.
